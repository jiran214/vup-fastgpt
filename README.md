# 使用说明
## 前置步骤
1. 安装VTS，并导入黑小优模型，可在VTS播放并测试动作
2. 安装 [虚拟麦克风VB](https://www.lanzoux.com/iC0pFfo8raj)
3. OBS(可选)
4. 双击运行文件夹下的"安装.bat"文件

## 配置声音输入输出
1. windows右下角小喇叭选择 VB，音源作为输出
2. 配置直播的输出音源为VB
3. 配置VTS的麦克风输入音源为VB（不同直播机操作不同）=
4. 完成上述步骤，此时电脑发出的任何声音会被VTS、直播机、VB接收，这三个界面都会显示音量大小

## UI参数配置(大部分已配置好)
1. [FastGPT](http://ai.newhopedairy.cn/app/detail?appId=6558fcbced049c3059f0e1d8)可做配置
   - 提示词配置
   - 知识库配置
   - 动作配置(不需要动)
2. [直播间配置](http://localhost:8501/%E7%9B%B4%E6%92%AD%E9%97%B4%E9%85%8D%E7%BD%AE)
   - B站账号配置
   - 视频号扫码登录
   - 直播话术
3. [虚拟人](http://localhost:8501/%E8%99%9A%E6%8B%9F%E4%BA%BA%E9%85%8D%E7%BD%AE)配置
   - 音色
   - 其它已配置好
4. 调度任务配置，包括定时和循环任务
    - 在"3_任务配置页面表格"修改

## 运行
1. 点击 "B站或者视频号开播"
2. 视频号需要在弹出的网页扫码登录


## 注意事项
- 在页面操作完成后，请点击保存按钮
- 打开程序，请勿关闭终端，终端会有运行日志
- 如果运行有问题，可以找到"项目目录/log"文件夹，将当天日志发给我
