# 使用说明
## 前置步骤
1. 安装VTS，并导入黑小优模型
2. 安装虚拟麦克风VB，
3. OBS(可选)

## 配置声音输入输出
1. windows右下角小喇叭选择 VB，音源作为输出
2. 配置直播的输出音源为VB
3. 配置VTS的麦克风输入音源为VB（不同直播机操作不同）
4. 完成上述步骤，此时电脑发出的任何声音会被VTS和直播机接收，VB界面会显示音量大小

## UI参数配置(大部分已配置好)
1. FastGPT可做配置
   - 提示词配置
   - 知识库配置
   - 动作配置(不需要动)
2. 直播间配置
   - B站账号配置
   - 视频号扫码登录
   - 直播话术
3. 虚拟人配置
   - 音色
   - 其它已配置好
4. 调度任务配置，包括定时和循环任务
    - 在"3_任务配置页面表格"修改

## 运行
1. 点击 "B站或者视频号开播"
2. 视频号需要在弹出的网页扫码登录
3. 首次运行会测试


## 注意事项
- 在页面操作完成后，请点击保存按钮
- 打开程序，请勿关闭终端，终端会有运行日志
- 如果运行有问题，可以找到"项目目录/log"文件夹，将当天日志发给我
